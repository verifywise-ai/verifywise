# Agent Guidance — VerifyWise

This project uses an expanded AI-agent roster under `agents/`.

- **`agents/agent.md`** — Master Orchestrator prompt. Start here to activate the multi-agent workflow.
- **`agents/00-TEAM_WORKFLOW.md`** — The 12-phase interactive delivery lifecycle.
- **`agents/README.md`** — Human-readable roster index.
- **`agents/roster.json`** — Machine-readable agent index.

When modifying agent files, update `roster.json` and the Dispatch Matrix in `agent.md` if task routing changes.
